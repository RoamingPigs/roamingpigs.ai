Computer Architecture · Physical Limits

The Physical Constraints of Local Inference

Three physical realities that govern autoregressive token generation regardless of software frameworks or compiler optimizations.

Constraint 1 · The Autoregressive Memory Wall

Single-batch decoding is memory-bandwidth bound, not compute-bound

Generating each token in autoregressive decoding requires streaming every active model parameter through the memory controller to the ALUs exactly once. At batch size 1, the arithmetic intensity is roughly 1 FLOP per byte transferred. Raw floating-point compute capacity sits largely idle waiting for weights to arrive from DRAM. Token generation speed is physically bounded by sustained memory bandwidth divided by active model size.

Constraint 2 · Prefill vs. Decode Thermodynamics

Prompt ingestion and token generation have a 20× energy asymmetry

During prompt ingestion (prefill), N input tokens are processed concurrently via dense matrix multiplications, achieving high arithmetic intensity and high power efficiency per token. During decode, gigabytes of silicon weights move across the memory bus to emit a single token. This creates a severe thermodynamic asymmetry: decode draws 15× to 25× more Joules per token than prefill.

Constraint 3 · Quantization Pareto Frontier

4-bit to 5-bit quantization delivers near-lossless perplexity at half the bus traffic

Empirical perplexity sweeps demonstrate that modern block-wise quantization formats (such as Q4_K_M and IQ4) preserve over 98% of baseline FP16 model quality while cutting memory bus traffic by more than 65%. Running FP16 weights on memory-constrained buses burns twice the thermodynamic energy and halves generation throughput with negligible downstream reasoning improvement.

Systems Engineering · Production Rules

Field Rules for Machine Agency

Patterns that hold up in production after the venture capital marketing has worn off.

Rule 1 · Verification Beats Parameter Scale

A verified 14B model outperforms an unverified 70B model

Scaling model size provides diminishing returns on domain accuracy compared to allocating test-time compute to structured verifiers, deterministic parsers, and unit tests. A compact model coupled with calibrated abstention delivers higher operational reliability at a fraction of the memory footprint and latency.

Rule 2 · Unified Memory Eliminates PCIe Bus Hops

Zero host-to-device transfers for single-node workloads

Discrete multi-GPU configurations incur latency penalties across PCIe slots and NVLink topologies. Unified memory architectures with 128 GB+ capacity allow the CPU and GPU to share a single coherent address space, enabling large-context KV caches and weight residency without bus migration penalties.

Rule 3 · Measure Wall-Socket Power, Never Package TDP

Silicon PPT ignores memory, fans, and power conversion losses

Hardware vendor software telemetry (such as package power tracking) frequently excludes the memory bus, cooling system, and AC-to-DC power supply inefficiencies. True operational expenditure must be measured at the physical wall socket under full memory bus saturation.
