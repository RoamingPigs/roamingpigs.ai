How these are built

Assumptions in view

Every default has a source and a date. Every input can be changed, and the page URL keeps your choices so you can share them.

Measured, modelled or assumed

Each number carries a mark. A formula output is never presented as a reading, and an assumption is never presented as a measurement.

Limits first

Each instrument says what it does not model. The calculator is an optimistic upper bound for batch size one, not a forecast for a busy server.

The record behind the numbers

The measurements these instruments use are published as dated records with their sample sizes and limits on roamingpigs.org. When I find a mistake, it goes in the corrections log.
