What does a model cost to run?

Pick a model and a machine. Memory, decode speed, energy per token and cost per million tokens appear with their assumptions beside them.

Batch size one. This models one request at a time, which is how a single person uses a local machine. A busy server batches many requests and changes the energy and cost per token several-fold, so do not read these figures as a forecast for one. Speed is an upper bound, checked against wall-meter runs on one machine only. How it works.
